Remove from your tabs?

This just takes this list off your device — nobody else is affected, and the list itself (and everyone else's access to it) stays exactly as it is. You'd need the share link again to get it back.

Delete this list for everyone?

This is not the same as removing it from your device. It permanently deletes this list from the shared database — its items, categories, and everything in it — for every person who has this list's code, not just you. This can't be undone. Only do this if you're sure nobody else still needs it.
